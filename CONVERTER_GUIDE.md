# 🎬 Как сконвертировать WebM в MP4

## ⚡ ВСТРОЕННЫЙ КОНВЕРТЕР (самый простой способ)

Прокрутите страницу анимации вниз — вы увидите раздел **"🎬 Конвертер WebM → MP4"**

### Как использовать:
1. Запишите видео кнопкой **"⏺ Записать видео"**
2. Файл WebM скачается автоматически
3. Прокрутите страницу вниз до конвертера
4. Перетащите WebM файл в область конвертера (или нажмите для выбора)
5. Дождитесь окончания конвертации (прогресс-бар покажет %)
6. Нажмите **"💾 Скачать MP4"**

**Преимущества:**
- ✅ Работает прямо в браузере
- ✅ Не нужно устанавливать программы
- ✅ Не нужно загружать файлы на сторонние сайты
- ✅ Быстро и безопасно

## 💻 ЛОКАЛЬНАЯ КОНВЕРТАЦИЯ (FFmpeg)

### Установка FFmpeg:

**macOS:**
```bash
brew install ffmpeg
```

**Windows:**
```bash
winget install ffmpeg
```
Или скачайте с https://ffmpeg.org/download.html

**Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install ffmpeg
```

### Конвертация:

Откройте терминал/командную строку и выполните:

```bash
ffmpeg -i transformer-animation-*.webm -c:v libx264 -preset slow -crf 18 -c:a aac -b:a 192k transformer-video.mp4
```

**Параметры:**
- `-c:v libx264` — видеокодек H.264 (совместим со всеми плеерами)
- `-preset slow` — медленное кодирование для лучшего качества
- `-crf 18` — качество (18 = высокое, 23 = среднее, 28 = низкое)
- `-c:a aac` — аудиокодек AAC
- `-b:a 192k` — битрейт аудио 192 kbps

### Быстрая конвертация (меньше размер):
```bash
ffmpeg -i transformer-animation-*.webm -c:v libx264 -crf 28 transformer-video.mp4
```

### Максимальное качество:
```bash
ffmpeg -i transformer-animation-*.webm -c:v libx264 -preset veryslow -crf 15 -c:a aac -b:a 320k transformer-video.mp4
```

## ❓ ЧАСТЫЕ ВОПРОСЫ

### Встроенный конвертер не работает
**Решение:** Используйте Chrome или Edge. Firefox и Safari могут не поддерживать WebCodecs API.

### Онлайн конвертеры слишком медленные
**Решение:** Используйте встроенный конвертер или FFmpeg — они работают локально и быстрее.

### Нужен именно MP4 для GitHub
**Решение:** GitHub поддерживает WebM, но MP4 имеет лучшую совместимость. Используйте встроенный конвертер.

### Видео слишком большое после конвертации
**Решение:** Используйте FFmpeg с параметром `-crf 28` для меньшего размера:
```bash
ffmpeg -i input.webm -c:v libx264 -crf 28 output.mp4
```

```bash

chmod +x upload-to-github.sh
./upload-to-github.sh

# Windows:
.\upload-to-github.ps1
```

1. ✅ Создаст репозиторий **electro**
2. ✅ Загрузит все файлы
3. ✅ Настроит git remote
4. ✅ Выполнит push

# 🔥 Как работает трансформатор — Вирусная анимация

Интерактивная образовательная анимация о работе трансформатора в стиле 3Blue1Brown, оптимизированная для TikTok/Reels.

## ✨ Особенности

- 🎬 **60-секундная анимация** в вертикальном формате 9:16
- 🔊 **Голосовая озвучка** на русском языке (Web Speech API)
- 📝 **Синхронизированные субтитры** для каждой сцены
- 🎨 **Вирусные визуальные эффекты**: молнии, частицы, взрывы энергии
- 📊 **6 сцен**: от шокирующего хука до призыва к подписке
- 💾 **Запись в WebM** с возможностью конвертации в MP4

## 📥 Как сохранить видео с озвучкой

### Метод 1: Через браузер (WebM → MP4)

1. Откройте анимацию в браузере
2. Включите озвучку кнопкой **"🔊 Озвучка ВКЛ"**
3. Нажмите **"⏺ Записать видео"**
4. Дождитесь окончания 60-секундной записи
5. Файл `transformer-animation-{timestamp}.webm` скачается автоматически
6. Конвертируйте WebM в MP4:
   - Онлайн: [cloudconvert.com](https://cloudconvert.com/webm-to-mp4)
   - Локально: `ffmpeg -i input.webm -c:v libx264 -c:a aac output.mp4`

### Метод 2: Через OBS Studio (рекомендуется)

1. Установите [OBS Studio](https://obsproject.com/)
2. Создайте новую сцену → Источник: "Захват окна" → выберите браузер
3. Настройки вывода:
   - Формат: MP4
   - Кодировщик: x264
   - Битрейт: 8000 Kbps
   - FPS: 60
4. Включите озвучку в анимации
5. Нажмите "Запустить запись" в OBS
6. Воспроизведите анимацию полностью
7. Остановите запись — готовый MP4 файл сохранится в папке OBS

### Метод 3: Запись экрана (macOS/Windows)

**macOS:**
```bash
# Встроенная запись экрана
Cmd + Shift + 5 → Выбрать область → Записать
```

**Windows:**
```bash
# Xbox Game Bar
Win + G → Захват → Начать запись
```

## 📤 Загрузка на GitHub

### Вариант 1: Через веб-интерфейс

1. Откройте ваш репозиторий на GitHub
2. Нажмите **"Add file"** → **"Upload files"**
3. Перетащите MP4 файл
4. В описании коммита напишите: "Добавлено видео с озвучкой"
5. Нажмите **"Commit changes"**

### Вариант 2: Через Git CLI

```bash

git add video.mp4
git commit -m "Добавлено видео с озвучкой"
git push origin main
```

### Вариант 3: GitHub Releases (для больших файлов)

1. Перейдите в репозиторий → **"Releases"** → **"Draft a new release"**
2. Загрузите MP4 файл

5. Нажмите **"Publish release"**

## 🔧 Технические детали

- **Разрешение**: 1080x1920 (9:16)
